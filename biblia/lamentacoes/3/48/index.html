Comentário de João Calvino

Os intérpretes dão explicações diferentes para o início deste versículo: alguns o traduzem assim: “Meu olho desce até rios de águas”; outros, “Meu olho flui até rios de águas”, ou “rios de águas fluem para baixo”. Mas, como expliquei em outro lugar, o Profeta quer dizer antes que seu olho desceu como rios; e descer, ou escorrer para baixo, é uma metáfora para fluir, pois a água, como bem se sabe, desce quando flui.…
