Cantares 7:2

Teu umbigo é como uma taça redonda, que não falta bebida; teu abdome é como um amontoado de trigo, rodeado de lírios.

KJV Thy navel is like a round goblet, which wanteth not liquor: thy belly is like an heap of wheat set about with lilies.

RVA Tu ombligo, como una taza redonda, que no le falta bebida. Tu vientre, como montón de trigo, cercado de lirios.
