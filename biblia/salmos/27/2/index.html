Comentário de João Calvino

Quando os maus, etc. Não há razão para traduzir esta frase, como fazem alguns intérpretes, no tempo futuro. Mas, embora conservemos o tempo passado que o profeta emprega, as palavras podem ser explicadas de duas maneiras. O significado, mas nos escritos proféticos é muitas vezes usado para o futuro. Não parece haver, no entanto, como observa Calvino, qualquer necessidade de traduzir os verbos para o tempo futuro…
