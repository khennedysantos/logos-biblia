Ezequiel 24:2

Filho do homem, escreve para ti o nome deste dia, hoje mesmo; porque o rei da Babilônia chegou a Jerusalém hoje mesmo.

KJV Son of man, write thee the name of the day, even of this same day: the king of Babylon set himself against Jerusalem this same day.

RVA Hijo del hombre, escríbete el nombre de este día: el rey de Babilonia se puso sobre Jerusalem este mismo día.
