Comentário de João Calvino

Alguns, quando ouviram, etc. Davi falou dos pais como se toda aquela geração fosse incrédula; mas parece que alguns que verdadeiramente temiam a Deus se misturavam aos ímpios. O apóstolo menciona isto para modificar o que Davi dissera de forma mais severa, a fim de que saibamos que a palavra é pregada a todos com este propósito, para que todos a obedeçam com um só consentimento, e que o povo inteiro foi justamente…
