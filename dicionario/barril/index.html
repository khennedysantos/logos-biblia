Barril

Easton · em inglês: Barrel

Vasilha usada para guardar farinha (1 Reis 17:12, 14, 16).

A mesma palavra (cad), assim traduzida, também é vertida como “cântaro”, vasilha para carregar água (Gênesis 24:14; Juízes 7:16).

Texto original (inglês)

A vessel used for keeping flour (1 Kings 17:12, 14, 16).

The same word (cad) so rendered is also translated "pitcher," a vessel for carrying water (Gen. 24:14; Judg. 7:16).
