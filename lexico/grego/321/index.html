ἀνάγω

anágōG321

conduzir para cima; por extensão, trazer para fora; especialmente, zarpar

Como a KJV traduz

trazer (de novo, para fora, para cima de novo), partir, lançar (para frente), conduzir (para cima), soltar, oferecer, navegar, colocar em marcha, retomar
