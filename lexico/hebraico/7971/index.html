שָׁלַח

shâlachH7971

enviar para longe, para ou para fora (em grande variedade de aplicações)

Como a KJV traduz

[de] qualquer modo, designar, trazer (pelo caminho), lançar (fora, para fora), conduzir, fervorosamente, abandonar, dar (desistir), crescer longo, pôr, deixar, deixar partir (descer, ir, soltar), empurrar para longe, pôr (para longe, para diante, em, para fora), estender a mão, enviar (para longe, para diante, para fora), estabelecer, lançar (para diante, para fora), semear, espalhar, estender (para fora)
