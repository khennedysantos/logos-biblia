(todo) ao longo, depressa, comportar-se, vir, (em) continuamente, ser familiar, partir, ser aliviado, entrar, exercitar-se, seguir, adiante, para frente, obter, ir (por aí, para fora, ao longo, embora, para frente, adiante, para fora, para cima, de um lado para outro), maior, crescer, ter o hábito de assombrar, conduzir, marchar, cada vez mais, mover-se, precisar, em, passar (embora), estar no ponto, bastante, correr (ao longo), enviar, rapidamente, espalhar, ainda, certamente, difamador, viajar (viajante), andar (no exterior, em, de um lado para outro, para cima e para baixo, a lugares), vaguear, crescer, (homem de estrada), estar fraco, rodopiar
